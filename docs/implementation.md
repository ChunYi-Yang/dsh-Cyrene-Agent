# DSH 安装并启动 Cyrene

目标：Windows x64 电脑从 DSH 添加 GitHub 插件后，点击入口自动下载固定版本便携程序、校验并启动；无需开发环境、手动目录或本地 AI 模型。

设计：根目录插件包提供安装入口；插件在当前 DSH profile 对应的独立用户目录存储程序和私人数据。首次点击使用随插件分发的固定版本及 SHA-256 清单下载 GitHub Release ZIP，校验后安全解压并原子安装。连接信息只由当前 DSH 生成。失败保留原程序和用户数据，显示可重试错误。不修改 DSH 可执行文件，不使用 postinstall。

程序包含 Electron、已构建的 Cyrene、基础角色与合法许可；不包含源码工作区、用户配置、日志、聊天、推理权重、向量及语音模型。已有 DSH 模型配置沿用原生通道。

实施步骤：
- [x] 根目录安装入口与带失败边界测试的下载管理器。
- [x] 插件准备状态、进度、启动与免手动配置的连接。
- [x] 只读源码打包脚本、程序清单和发布检查。
- [x] 隔离目录安装、离线复用及真实程序启动验证。

发布条件：程序资产必须上传到清单中固定的 GitHub Release 地址后，才能声称其他电脑在线安装可用。新目录中的源码和程序资产都需隐私检查，未发布不冒充上线。

验证：9 项自动测试通过；隔离 DSH 原生加载、空成员团队接口、真实 ZIP 校验解压、离线复用、Electron 欢迎页面 DOM 与截图、正常退出均通过，未调用模型。当前构建基础为最新团队版；发布源仅保留插件与打包工具，不携带开发仓库历史。

排障记录：初版冒烟只检查控制接口后立即退出，可能打断首次页面加载。验收已改为等待页面完成、检查实际 DOM 和截图再退出。Windows PowerShell 解压已覆盖长路径、目录穿越、备用数据流及保留设备名。
