# 如我所书

DSH Desktop 的本地 Cyrene 窗口切换、历史查看、同会话续聊与模型配置同步插件。只控制配置的集成目录；不接收任意命令，不读取聊天数据库。模型密钥只通过本机主进程和 DSH 原生凭据服务处理。状态通过受认证的本机控制接口确认；退出走 Cyrene 自身的保存与清理流程，不停止 DSH。

从 GitHub 下载仓库并在 DSH 原生插件管理器中选择本插件目录 `plugins/ruwo-suoxie`。如果插件管理器需要 ZIP，压缩该目录的内容后导入。不需要发布或安装 npm 包。安装后配置 `integrationRoot` 为本机 Cyrene Next 集成目录；该绝对路径只保存在本机 DSH 配置中，不要提交 Git。安装并配置后，在侧栏选择“如我所书”。插件依赖 DSH 的 `connection`、`sessionController` 与客户端 `slots/layout` 服务。桌面切换请求确认 Cyrene 控制接口成功后才隐藏 DSH，失败保留当前窗口；Windows 隐藏操作只匹配已安装 DSH 可执行文件，不终止进程。

插件另提供仅限 DSH owner connection 的 Session Controller 网关；Cyrene main 可用会话身份调用 DSH `list/create/selectModel/prompt/page/follow/attachment`，并按行读取完整事件 envelope。Cyrene 左栏会话记录直接读取此通道，显示服务与进程身份；主会话四模式现通过同一 Session API 执行，新任务保留持久会话映射、请求回执和人设作用域；DSH 的工具、安全政策和审批不被替代。双方原始历史定时更新；原生图片可读取预览，文件原件经原生上传保存。两端的共享会话页读取原生历史并提供文字续聊输入框，沿用原会话模型与权限；回复以原生事件为准。

点击“如我所书”弹出“进入翁法罗斯”和“觐见浮黎”；后者打开工作区/会话列表与续聊区域，不切换窗口。原“关闭如我所书”按钮已移除。Cyrene 的编辑/重生成入口在主进程拒绝本地历史分叉，需在 DSH 操作。

单托盘适配需在已单独安装的 Cyrene Next 集成目录中按其说明安装；本分支不包含托盘安装脚本。安装适配前需要先从托盘正常退出正式 DSH。适配器仅支持已验证的桌面版本和托盘结构，修改前在忽略目录备份原始程序；DSH 升级后应重新核验，不能直接沿用旧程序备份覆盖新版。当前桌面选择仅保存在 DSH 进程内：只有“进入翁法罗斯”和“返回 DSH”改变选择及托盘图标，关闭窗口不改变选择；完全退出 DSH 后重新启动默认选择 DSH。选择 Cyrene 时打开失败会保留选择并提示，不自动切回 DSH。身份描述和本机安装目录不进入 Git。

Cyrene 功能插件设置新增 DSH 插件页，通过固定认证网关读取原生 pluginManager 的目录并执行启停、npm 包安装。原生保护项和如我所书连接插件不可从此页停用；安装权限和兼容性检查仍由 DSH 决定，原生要求重启时只提示，不自动重启。卸载、更新、插件设置和本地包使用正式 DSH 插件中心；Cyrene 原插件保留单独页签。

启动 Cyrene 或重新加载 DSH 时同步完整已载入模型目录，运行中每分钟刷新；连接未就绪时保留缓存并重试。DSH 密钥不会复制到 Cyrene，目录项使用原生路由引用。Cyrene 自建的 OpenAI Chat Completions、Responses、Anthropic API 配置通过 owner 认证的本机接口导入现有原生 pi-ai 适配器，密钥存入 DSH 凭据服务，设置写入原生配置服务并检查版本。默认模型与既有会话选择保持原值。仅更新本插件拥有且未被原生编辑的导入项，冲突保留现状，不删除旧配置；OAuth 授权留在原端使用。导入所有权摘要位于忽略的 `.local/model-sync-ownership.json`，应随本机数据保留。


旧 Cyrene 记录首次在 DSH 续聊时，通过认证本机接口读取并建立固定原生会话映射，按原模式安装人设与归档上下文；原记录保留。原生创建使用稳定身份，接入配置未完成会留下待完成标记，重试沿用同一会话。

文字续聊由原生 Session Controller 排队，不另建模型循环，不改变已有模型、工具权限或审批配置。请求回执存于忽略的 .local/desktop-continuations；响应未知时保留同一请求和输入，跨重启重试仍用相同身份。该目录含私人输入，禁止上传。附件、审批、编辑与重生成仍使用 DSH 原生入口；当前新增续聊输入框只提交文字。
